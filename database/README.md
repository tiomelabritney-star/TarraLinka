# TarraLinka Database

## Overview
This folder contain the database design and data management structure for TarraLinka

## Main Data Entities
- Users
- Farmers
- Buyers
- Products
- Orders
- Payments
- Transporters
- Deliveries
- Suppliers

  ## Database Technology
  PostgreSQL

  ## Responsibilities
  - Store application information.
  - Maintain relationships between records.
  - Protect data integrity.
  - Support reliable data retrieval and updates.

    ## Project status
