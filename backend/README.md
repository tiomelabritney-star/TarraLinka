# TarraLinka Backend

## Overview
The backend is responsible for processing requests, managing business logic and communicating with the database.

## Main Responsibilities
- User authentication and authorization
- Farmer management
- Agricultural product management
- Order processing
- Transportation management
- Payment processing
- Database communication

## Technology
- Node.js
- NestJs
- PostgreSQL
- REST API

  ## Project Status
  Backend development is in the planning stage
